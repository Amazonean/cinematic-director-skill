# Cinematic Director Skill

**A Claude Code skill that thinks like a film director.**
It turns an idea, script, product or brand brief into a production-ready plan for AI video tools.

🟡 **Status:** in development.

> The source code is private. This page explains what the skill does.

---

## What it does

- Takes an idea, script, image, storyboard or product brief.
- Plans the story first: shots, camera moves, lighting and pacing.
- Writes prompts for the AI video tool you choose.
- Works with many video generators, for example Seedance, Kling, Veo, Hailuo and PixVerse.

## Main rule

**Think like a director, not a prompt writer.** The story and the shots come first. The prompts come last.

---

## Tech

- **Claude Code** skill and agents
- Node.js server for jobs, presets and templates
- A review step that checks each output before it is used
